Nitro considers all API calls without a domain to be "internal API" and [calls them directly](https://nuxt.com/docs/api/utils/dollarfetch).  
This behavior causes `404: Page Not Found` error only in SSR when calling SWA built-in APIs such as `/.auth`.

To solve this problem, Nuxt SWA provides server proxies for `/.auth`.

## Usage

Since this is used internally by `useEasyAuth`, you typically do not need to be aware of it.
